# Metevra Weather — GitHub Android Build

This project is prepared for GitHub Actions Android builds.

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root (not the outer ZIP folder).
3. Push to `main`, or open **Actions → Build Metevra Weather Android → Run workflow**.
4. When the job finishes, open the workflow run and download the **metevra-weather-apk** artifact.

The release workflow is available under **Actions → Build Metevra Weather Release AAB → Run workflow**.

Package ID: `com.metevra.weather`
Version: `1.0.0`
Target API: 36
